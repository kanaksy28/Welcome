Open PowerShell as Administrator.
dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart

Wait until it says the operation completed successfully.
Then run: dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart

Step 2 — Restart your PC
Restart Windows now.
Dont skip this step because the features may not become active until after the restart.

Step 3 — Check WSL again
After restarting, open PowerShell and run:
wsl --status

If you don't have a Linux distribution installed yet, wsl -l -v may say that there are no distributions installed. That's okay.

COMMANDS
1. Verify installation
docker --version	    Displays Docker CLI version.
docker version	      Shows client and server versions.
docker info	          Displays Docker Engine configuration and details.
docker ps	            Lists running containers.

2. Essential Docker commands for the exam
A. Image commands
Command	                          Purpose
docker images	                    List downloaded/built images.
docker pull                       nginx	Download the Nginx image.
docker image inspect nginx	      Display detailed image information.
docker rmi nginx	                Remove an image if it is not in use.
docker build -t myapp:1.0 .	      Build an image from the Dockerfile in the current directory.

B. Container commands
Command	                           Purpose
docker run hello-world	           Create and run a container.
docker ps	                         List running containers.
docker ps -a	                     List all containers, including stopped ones.
docker start mycontainer	          Start an existing stopped container.
docker stop mycontainer	            Stop a running container.
docker restart mycontainer	        Restart a container.
docker rm mycontainer	              Remove a stopped container.
docker logs mycontainer	            View container logs.
docker exec -it mycontainer sh	    Open a shell inside a running container, if supported.
docker inspect mycontainer	        Display detailed container information.


C. Run, name and map ports
docker run -d --name web nginx
docker run -d -p 8080:80 --name web nginx
docker run -it ubuntu sh
docker run --rm hello-world

Understand the options:
- -d — run in the background.
- -it — interactive terminal.
- --name — assign a container name.
- -p 8080:80 — map host port 8080 to container port 80.
- --rm — remove the container automatically after it exits.


D. Dockerfile instructions
Instruction	                  Purpose
FROM	                        Select the base image.
WORKDIR	                      Set the working directory inside the image.
COPY	                        Copy files from the build context into the image.
RUN	                          Execute a command while building the image.
EXPOSE	                      Document the port the application listens on.
CMD	                          Specify the default command to run when a container starts.


E. Cleanup commands
docker stop web
docker rm web
docker rmi nginx
docker container prune
docker image prune

Step 1: Create the project
Create a folder called docker-practical and open it in VS Code.
docker-practical/
├── app.js
├── package.json
└── Dockerfile

Step 2: Write app.js
const http = require('http');
const server = http.createServer((req, res) => {
  res.writeHead(200, {'Content-Type': 'text/plain'});
  res.end('Hello! Docker Practical is Working!');
});
server.listen(3000, '0.0.0.0', () => {
  console.log('Server running on port 3000');
});


Step 3: Write package.json
{
  "name": "docker-practical",
  "version": "1.0.0",
  "main": "app.js",
  "scripts": {
    "start": "node app.js"
  }
}


Step 4: Create the Dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
COPY app.js .
EXPOSE 3000
CMD ["npm", "start"]


What happens during the build?
1. FROM downloads or uses the Node.js base image.
2. WORKDIR sets /app as the working directory.
3. COPY copies the project files into the image.
4. EXPOSE documents the application port.
5. CMD specifies how the application starts.


Step 5: Build the image
Open the terminal in the project folder:         docker build -t docker-practical:1.0 .
The final dot (.) means the current directory is the build context.

docker images
You should see docker-practical with tag 1.0.

Step 6: Run the container
docker run -d -p 3000:3000 --name myapp docker-practical:1.0
docker ps
Open http://localhost:3000 in your browser.


Step 7: Practise container management
docker logs myapp
docker stop myapp
docker start myapp
docker restart myapp
docker ps -a

To delete the container and rebuild after modifying the application:
docker stop myapp
docker rm myapp
docker build -t docker-practical:1.0 .
docker run -d -p 3000:3000 --name myapp docker-practical:1.0
